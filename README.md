# Aaris Rahman — Personal Portfolio Website

A fully professional personal portfolio website built with **HTML, CSS & JavaScript**.

## 🌐 Live Demo
> Deploy on GitHub Pages (free) — instructions below.

## ✨ Features
- 🎨 Clean light theme with minimal & modern design
- 📱 Fully responsive (mobile, tablet, desktop)
- ⌨️ Animated typing effect in hero section
- 📊 Animated skill bars on scroll
- 🎭 Scroll reveal animations
- 🍔 Mobile hamburger menu
- 📬 Contact form with feedback
- 🔝 Back-to-top button
- 🔗 Social links & project cards

## 📁 Sections
- **Hero** — Name, role typing effect, CTA buttons
- **About** — Personal info & background
- **Skills** — Animated skill progress bars
- **Services** — What I offer
- **Projects** — Portfolio project cards
- **Contact** — Contact form + details

## 🚀 Deploy on GitHub Pages (Free Hosting)
1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source: **Deploy from a branch → main → / (root)**
4. Your site will be live at: `https://your-username.github.io/portfolio-website`

## 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, CSS Variables, Animations)
- Vanilla JavaScript (IntersectionObserver, Typed Effect)
- Font Awesome Icons
- Google Fonts (Poppins)
